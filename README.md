# THE LAST ROOM

A psychological horror game about a place that should have been empty.

You were asked to inspect an abandoned house after its owner disappeared.

The electricity is still working.

The doors are still locked.

And someone appears to be inside.

---

## Status

🟡 Prototype

This project is currently under development.

## About

THE LAST ROOM is a first-person psychological horror experience focused on:

- realistic environments
- exploration
- environmental storytelling
- subtle sound design
- unsettling discoveries
- no unnecessary jump scares

## Warning

This game contains disturbing imagery, psychological horror, darkness, and themes of isolation.
